# 渠道、批量与保存修订

基于 74d54222，在 codex/channels-batch-output-2026-11-04 实施。用户五项需求为真实功能验收，不只改文案。

- 渠道：具名档案、当前渠道、增改删、重启恢复；密钥不回显，Windows 本机 DPAPI 保护。主动连接测试与模型探测，失败原因可读；OpenAI 兼容接口优先，保留其它旧引擎。
- 页面：默认全部，显式范围才限制页数。用超过五页的真实样本验证。
- 路径：默认目录单独保存并读回，当前结果可以另选；用户已明确源目录模式译文直接放在 PDF 旁边，历史在界面按文章归组。
- 输出：双语对照/仅译文开关明确双向绑定；创建、引擎回传、保存均尊重选择；中文后缀和版本，旧幂等保存回放兼容。
- 批量：显示多份文件、单项移除、批量提交计数和逐份状态，验证实际不止一个任务。布局使用现有 WPF UI + XamlFlair，统一 8/12/16/24 间距，滚动区和固定操作分离；不写 CSS/控件皮肤。

界面盘点：旧待上传 ListBox MaxHeight=52 只能露出一项；输出卡片无当前保存目录编辑；Export 优先旧 PlannedDirectory；ToggleSwitch 未显式 Mode=TwoWay。沿用五页导航，设置渠道区改为档案与编辑组合，工作台突出批量列表/全部页面/输出类型/保存位置，结果页按文章分组。

验收：渠道本机持久化/切换/密钥隔离/测试/模型列表；真实 7 页与多文件；单一输出保存准确；源目录旁和自定义目录实际文件；重启与幂等；浅深色、980 DIP 与关键状态运行图；独立复审后提交推送，仍不合并 main/tag/Release。OS 输入/DPI 未实际验证时如实保留。

协议依据：OpenAI Models/Chat API 官方文档、Claude Models API 官方文档；测试只用回环服务，不调用付费提供方。
